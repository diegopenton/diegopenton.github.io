01 — Personal research project · 2026–present

Project Argos

Making financial research easier to work with.

Papers contain useful ideas, but getting from a paper to something you can test takes a lot of work. Argos is our team’s attempt to connect research collection, document understanding, and strategy evaluation.

My part: I lead the system’s orchestration and build the research acquisition and ingestion engines. The team’s platform combines local language models, retrieval, and persistent memory.

The longer-term goal is testable strategies. The project is under development and used for research, not live trading.

  • Python
  • LLMs / RAG
  • Docker
  • DGX Spark
What makes this challenging?

A useful extraction needs to retain its source and the assumptions behind it. The corpus pipeline tracks provenance and rights classifications so a promising result can be traced back and checked. I’m also working on making formula and table extraction dependable enough for later research steps.

02 — Vulkan USA · Summer 2026

From scanned tables
to searchable records.

An OCR workflow for manufacturing documents.

I built a Python pipeline around TrOCR to read scanned factory records. The work included preparing images, labeling examples, training the model, and reviewing its output.

On the evaluated factory records, the workflow reached 92% character accuracy and 72.28% exact serial accuracy. Getting individual characters right was easier than recovering an entire serial number—one wrong character still makes the full serial incorrect.

  • PyTorch
  • Hugging Face
  • TrOCR
  • Python
Why keep a review step?

A plausible-looking serial number can still be wrong. I structured the workflow around preprocessing, labeling, and review so extracted records could be checked before being used for search or indexing.

03 — C++ course project · Spring 2025

Finding a route
through a network.

Airports as nodes. Flights as weighted edges.

Our team built a C++ system to explore airport connectivity. It includes shortest-path search, minimum spanning trees, connection counts, and route searches with stop constraints.

This small browser example lets you try the idea: change the destination or close a connection and see how the shortest route changes.

04 — Course research · Spring 2026

Comparing AI
coding assistants.

I designed repeatable Python tasks and API workflows to compare generated code. The evaluation covered correctness, readability, runtime, and security using Bandit and a consistent scoring framework.

The question was simple: how do you compare assistants fairly when a convincing answer isn’t necessarily working code?

  • Python
  • APIs
  • Bandit

Evaluation notes

  1. Same task.

    Standardized prompts keep the comparison consistent.

  2. Check the code.

    Correctness and performance are evaluated alongside readability.

  3. Look for risks.

    Security checks help catch issues a quick reading might miss.
